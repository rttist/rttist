# @rttist/typegen-plugins-ttypescript
<sup><i>Pronounce /ˈɑː(r)tɪst/ the same like "Artist".</i> Means Run-Time Type Information System for Typescript.</sup>

> Rttist typegen plugin adding support for ttypescript compatible tools such as Webpack's ts-loader or ttypescript itself.

For more information see our website [rttist.org](https://rttist.org) and docs [docs.rttist.org](https://docs.rttist.org).

## Versioning
This package is versioned by the `typescript` versions. 

New versions will be added only when there are some breaking changes in typescript compiler API, so use the latest version lower or equal to your TypeScript version.
In case of any problems, please file an issue.
