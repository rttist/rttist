# swc-plugin-rttist

> Rttist typegen plugin adding support for SWC.

For more information see our website [rttist.org](https://rttist.org) and docs [docs.rttist.org](https://docs.rttist.org).

## Versioning
This package is versioned by the `SWC` versions. 

New versions will be added only when there are some breaking changes in SWC API, so use the latest version lower or equal to your SWC version.
In case of any problems, please file an issue.
