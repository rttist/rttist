# Contributing Guide

Welcome and thank You for investing your time in contributing to my project! :tada:

## Requirements
- Install Rust,
- add wasm32-wasi target to Rust: `rustup target add wasm32-wasi`,
- add nightly toolchain to Rust: `rustup toolchain install nightly`,
- install swc CLI (using the nightly toolchain): `cargo +nightly install swc-cli`
